# AWS-VPC-Peering-Project
AWS VPC Peering Project completed as part of my cloud computing internship
## Project Overview
This project demonstrates VPC Peering in Amazon Web Services (AWS), enabling private communication between Virtual Private Clouds (VPCs).

## Objectives
- Create and configure VPCs.
- Establish a VPC peering connection.
- Configure route tables for communication between VPCs.
- Configure security groups to control network traffic.

## Technologies Used
- Amazon Web Services (AWS)
- Amazon VPC
- VPC Peering
- Route Tables
- Security Groups

## Implementation
The project involves creating VPCs, establishing a peering connection, and configuring the necessary routes and security rules.

## Learning Outcomes
- Understanding AWS networking.
- Learning VPC routing and peering.
- Gaining practical cloud computing experience.
